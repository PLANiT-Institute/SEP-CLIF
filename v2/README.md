## v1에서 바뀐 것

  '40년 전체 100.6TWh·14.2GW, 추세 제외 순증분 84.9TWh·11.9GW(당초 42.1TWh·6.2GW). 11차 전기본은 비교로 남김.
- **① 전력이 병목**: 헤드라인을 12차 재전망 기준으로 바꾸고, 한전 공급가능 판정(64%)이 '23.8월 기준임을 밝힘.
  11차 `increment_twh`는 '추세 대비 증분(추가수요)'으로 정의를 적음. 연혁표에 공청회 발표, KEEI 4차 토론회 추정,
  AIDC 특별법 시행령 입법예고('26.11.20)를 더함. 새 파일 `s1_dc_demand_outlook.csv`.
- **② 가스는 빠른가**: KPX 추진현황 10개 회차('16Q4~'26H1, '22Q4는 판독 불가)를 이어 사업 334개를 만들고, 끝난 사업과
  진행 중 사업의 허가→준공 기간을 나눠 봄(표본 편향 수정). 허가일은 어느 회차에서든 가장 이른 날짜('24H2부터 신재생 목록은
  최근 변경허가일을 싣기 때문). 새 파일 `s2_kpx_cross_edition_medians.csv`, `s2_kpx_cross_edition_projects.csv`.
  영문판 연간 순증 그래프에서 LNG만 그려지던 버그 수정. 연도별 진입 예정 그래프는 태양광·풍력 두 패널에 계획별 선으로. 순증 그래프 캡션에 '02·'05 LNG 통계 재분류를 적음.
- **③ 숨은 비용**: 탄소비용을 발전부문 유상할당 비율('26 15% → '30 50%, 기후부 2025.11.11)로 낸 실제 부담과
  전량 유상 상한으로 나눔. 새 파일 `s3_carbon_cost_allocation.csv`. 정산단가 CSV에서 태양광·풍력 거래가 없던 달의 0을 빈칸으로.
- **④ 재생 포트폴리오**: 헤드라인에 일 단위 변동계수는 3:7에서 오히려 커진다는 점과 2025년 시장 거래분 기준임을 더함.
- **⑤ 청정전력 전략**: 재생 대체량을 30TWh에서 12차 재전망 데이터센터 '40 수요(84.9·100.6TWh)로 바꿈.
  발전원별 발전량을 11차 전기본(정부 계획)과 KEEI 기준안(기준 전망)으로 나눠 자료별·연도순 누적 막대로 비교(이어 붙이지 않음).
  새 파일 `s5_generation_mix_paths.csv`, `s5_gas_generation_paths.csv`.
  열소비율·LNG 열량·연료비 가정을 CSV 열과 화면에 밝힘. KEEI 기준안은 12차 재전망 이전 자료로 '참고' 표시.
